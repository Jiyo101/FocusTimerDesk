# FocusTimer Desk

FocusTimer Desk es una aplicación de escritorio desarrollada en C# y WPF que implementa un temporizador Pomodoro configurable. El usuario puede personalizar la duración de trabajo y descanso, alternar automaticamente entre modos y visualizar un historial de descansos. La interfaz es completamente escalable gracias al uso de Viewbox.

---

## ⭐ Características principales

- Temporizador Pomodoro funcional con cuenta regresiva  
- Modos **Trabajo** y **Descanso** con cambio automático  
- Configuración personalizada de minutos de trabajo y descanso  
- Historial de descansos anteriores  
- Contador de sesiones completadas  
- Interfaz escalable mediante Viewbox  
- Código limpio, organizado y comentado en C#  
- Proyecto ideal para iniciarse en WPF  

---

## 🛠 Tecnologías utilizadas

- C# (.NET)  
- WPF (Windows Presentation Foundation)  
- XAML  
- DispatcherTimer  
- TimeSpan  

---

## ▶ Cómo ejecutar el proyecto

1. Clonar este repositorio  
2. Cambiar repositorio a "D:\NombreCarpetaRepositorio\FocusTimerDesk"  
3. Ejecutar (usando dotnet run)
